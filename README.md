## Project Overview

Apex Roofing Service is an HTML website designed to present roofing-related information online. Its content gives visitors an overview of available roofing work, including repair services and roof installation.

The site is intended to support a roofing company that wants an accessible online location for its service information. Visitors can use the website as a central reference when looking into roofing repairs, installation work, and related support.

## Getting Started

First, copy the repository locally and move into the project folder:

```bash
git clone https://github.com/smaier1992/apex-roofing-service-web.git
cd apex-roofing-service
```

The project uses HTML, so the main HTML document can be opened directly in a browser. For a local server preview, serve the directory with:

```bash
python -m http.server 8000
```

Open `http://localhost:8000/` in your browser after the server starts.
